# Follow-ups on inspection findings

I put together a rough version of the follow-up idea. Can we turn this into a real feature on the inspection page?

The [HTML mock-up](follow-up.html) shows the interaction I had in mind, and the [draft product spec](PRODUCT-SPEC.md) has the context and a few notes. The mock-up is only a click-through: I have not connected it to the application or worked through how saving should work.

The main thing is that someone can flag a finding, leave a short reminder, come back later and clear it when it is dealt with. Keep the first version small and reuse what we already have. Please ask me about any behavior we need to decide before implementation.
