# Proposed journey

1. Open Vehicle comparison from the vehicle search page.
2. Select the vehicles to compare.
3. Read their vehicle details and inspection information side by side.
4. Enter a name and choose **Save Comparison Report**.
5. See a clear confirmation and open the saved report.
6. Return later, find the report in the saved list and reopen it.

Questions remain about selection, missing information, naming and saved data. Ask the presenter before treating the prototype as the specification.
